# Contributing

Thanks for helping improve JESON. Keep changes focused on its small, dependency-free, embedded-friendly design.

## Development

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug
cmake --build build
ctest --test-dir build --output-on-failure
```

Add a positive and negative test for behavior changes. Public API changes should also update the README, feature guide, examples, and changelog where relevant.

The reflection overload list is generated by `tools/generate_reflect.py`; do not edit that repetitive block by hand.

## Pull requests

- Keep JESON usable as a header-only library without mandatory dependencies.
- Avoid hidden heap use beyond containers explicitly chosen by the model/API.
- Preserve useful error paths and parser recovery when adding input types.
- Run the test suite on at least one supported compiler before submitting.
